- # Project layout

Keep these project files at the repository root:

- `AGENTS.md` — project instructions and file-location rules.
- `spec.md` — project requirements and specification.
- `prompts.md` — a record of requests, changes, and whether they worked.
- `index.html` — the single-file web app entry point; it must stay at the root for GitHub Pages.

Use the numbered folders for all other project files:

- `00_planning/` — notes and sketches.
- `01_data/` — data files.
- `02_validation/` — hand calculations and test cases.
- `03_output/` — screenshots and exported results.

Save every new file in the appropriate root location or numbered folder. Add other files only when they belong to the project and fit one of these locations.

After each request, add an entry to `prompts.md` describing what was asked, what changed, and whether it worked.
